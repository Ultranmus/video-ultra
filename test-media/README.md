# Test media

`pnpm media` builds `files/` (git-ignored) and `files/manifest.json`. The playground serves
`files/` at `/media/`.

- **Generated** files are synthetic (ffmpeg test patterns + tones) — no licence concerns.
- **Downloaded:** `bbb-1080p60.mp4` — "Big Buck Bunny" © Blender Foundation, CC BY 3.0
  (via test-videos.co.uk).
- **`private/`** (git-ignored): the owner's own phone recordings (iPhone HDR, portrait, slow-mo,
  HEIC). Never committed, never published.
